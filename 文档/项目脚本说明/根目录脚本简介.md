# 根目录脚本简介

## 1. 文档目的

本文档简要介绍项目根目录中的 Python 脚本，帮助刚接触项目的读者了解：

- 每个脚本解决什么问题；
- 脚本读取什么数据、产生什么结果；
- 哪些脚本会互相调用；
- 运行脚本前需要注意什么。

本文档只介绍项目根目录中的脚本，不展开 `data` 等子目录中的脚本。

## 2. 项目脚本概览

根目录目前共有 8 个 Python 脚本：

| 脚本 | 主要用途 | 主要输入 | 主要输出 |
| --- | --- | --- | --- |
| `adapter.py` | 检查并重新编号运动轨迹 CSV | `output` 中的轨迹 CSV | `output/renamed` 和 `mapping.json` |
| `build_input_groups.py` | 按预设根数从零生成 17 组结构数据 | 代码中的根数配方和可选随机种子 | `input.csv` |
| `filter_sensor_data.py` | 批量滤波六轴传感器数据 | `sensor_编号_ang角度.csv` | 滤波 CSV 和可选对比图 |
| `gather_data.py` | 整理并绘制 gather 运动数据 | `gather_编号_ang角度.csv` | 位移 CSV 和可选曲线图 |
| `generator.py` | 生成不与已有旋转结构重复的 37 位序列 | `input.csv` 或空输入 | 新增结构数据 |
| `motion_profile.py` | 生成梯形速度运动轨迹 | 代码顶部的速度和时间参数 | `output/V_*.csv` |
| `rotate_force.py` | 将不同角度的力数据旋转到统一坐标系 | 六轴 sensor CSV | `data/datanew` 中的 CSV |
| `visualize_hex_lattice.py` | 绘制结构大图并导出每组的六种旋转图 | `input.csv` | `hex_lattice.svg` 和 `rotated_plots` 中的 SVG |

## 3. 各脚本简介

### 3.1 `adapter.py`

`adapter.py` 是运动轨迹文件的检查和重命名工具。

脚本会读取 `output` 文件夹顶层的 CSV，计算每个文件完整 `x` 列的有符号总和，并检查其中的最大值是否超过 `2000 mm`。这里检查的是位移增量的代数和，并不是每一步移动距离绝对值的总和。检查通过后，脚本按文件名顺序将文件复制并重命名为 `1.csv`、`2.csv` 等，同时生成 `mapping.json`，记录新编号与原文件名的对应关系。

主要配置位于代码顶部：

- `INPUT_DIR`：输入文件夹，默认是 `output`；
- `OUTPUT_DIR`：重新编号后的输出文件夹，默认是 `output/renamed`；
- `MAX_DISTANCE_MM`：允许的最大 X 位移总和，单位为毫米。

注意：如果距离检查失败，脚本会直接清空 `output/renamed` 中的全部文件和子目录。运行前必须确认其中没有需要保留的结果，必要时先备份。脚本成功运行时只覆盖本次产生的编号文件；如果上一次文件更多，旧的高编号文件可能残留，重新生成前也应检查输出目录。

该脚本使用相对路径，建议从项目根目录运行：

```powershell
py -3.11 adapter.py
```

### 3.2 `build_input_groups.py`

`build_input_groups.py` 是批量构建 `input.csv` 的推荐入口。

脚本按照代码中的 `ROOT_COUNT_RECIPE` 配方生成 17 组数据。每组数据包含 37 个 `0` 或 `1`，其中 `1` 表示对应六边形点位被选中。它不会自己实现随机生成，而是多次调用 `generator.py`，最后再检查总行数、每行列数、取值范围和每行的 `1` 数量。

常用命令行参数：

- `--output`：指定输出 CSV，默认是 `input.csv`；
- `--overwrite`：允许覆盖已有输出；
- `--seed`：指定随机种子，使随机结果可以重复生成。

示例：

```powershell
py -3.11 build_input_groups.py --overwrite --seed 42
```

### 3.3 `filter_sensor_data.py`

`filter_sensor_data.py` 是当前统一的六轴传感器滤波脚本，用于处理无表头、逗号分隔的六列 CSV。六列依次解释为：

```text
TX, TY, TZ, FX, FY, FZ
```

其中 `TX、TY、TZ` 通常表示三个方向的力矩，`FX、FY、FZ` 通常表示三个方向的力。

脚本支持两种滤波方式：

- `lowpass`：Butterworth 低通滤波，用于保留缓慢变化并削弱高频噪声；
- `bandpass`：Hamming 窗 FIR 带通滤波，只保留指定频率范围。

处理流程包括：读取六列数据、裁剪首尾样本、修复较短的内部缺失区间、对选定列滤波、保存滤波 CSV，以及按需生成滤波前后对比图。

“滤波器阶数”控制 Butterworth 截止频率附近衰减的陡峭程度，阶数越高，频率分界通常越明显。“FIR 长度”是 FIR 滤波器使用的系数数量，长度越大通常频率分辨能力越强，但需要更长的数据并增加计算量。

当前默认配置写在代码顶部，包括：

- 输入路径和输出路径；
- 滤波模式与采样率 `fs`；
- 截止频率、滤波器阶数或 FIR 长度；
- 需要滤波的列；
- `trim_head` 和 `trim_tail`；
- 是否绘图以及是否覆盖已有结果。

命令行参数可以临时覆盖代码顶部的默认值。例如：

```powershell
py -3.11 filter_sensor_data.py --input-path data/model_2 --mode lowpass --cutoff 5
```

如果输入是文件夹，结果默认保存在该文件夹的 `sensor_filtered` 子目录中。CSV 名称为 `原文件名_lowpass_filtered.csv` 或 `原文件名_bandpass_filtered.csv`，对比图名称为 `原文件名_lowpass.png` 或 `原文件名_bandpass.png`。

当前代码顶部的 `overwrite_existing = True`，因此同名结果会被直接覆盖；`make_plots = True` 表示默认生成对比图。运行前应确认旧结果是否需要保留，也可以把这两个变量改成 `False`，或者使用 `--no-overwrite`、`--no-plot` 临时关闭。

`trim_head` 和 `trim_tail` 的单位是样本行数。对应秒数的换算公式是：

```text
秒数 = 样本行数 / fs
```

### 3.4 `gather_data.py`

`gather_data.py` 用于整理 gather 运动数据。原始 gather CSV 没有表头，使用空白字符分隔，每行结构为：

```text
时间戳 + N 组（位移、速度、附加值）
```

脚本会根据实际列数自动判断通道数，因此可以处理不同数量的运动通道。它不会直接使用第一列原始时间戳，而是根据样本序号和 `fs` 重新生成从 0 开始的秒时间轴。它会导出经过单位换算和 Offset（偏移）处理的位移数据，还可以生成位移和速度曲线图。

Offset 用于消除初始位置偏差，支持三种模式：

- `initial`：减去每列第一个样本；
- `fixed`：减去一个固定数值；
- `none`：不减偏移。

常用命令行参数：

- `--input-path`：原始 gather CSV 所在文件夹；
- `--output-path`：输出文件夹；
- `--fs`：采样率；
- `--offset-mode`：Offset 模式；
- `--fixed-offset`：固定 Offset；
- `--no-plot`：只导出 CSV，不生成 PNG。

注意：当前代码默认路径是项目根目录下的 `model_1`，而项目实际原始数据通常位于 `data/model_1`。直接运行前应修改顶部的 `inputpath`，或通过 `--input-path data/model_1` 明确指定输入目录。

未指定输出目录时，结果写入 `输入目录/gather_figure`。位移文件名为 `原文件名_disp_data.csv`，曲线图文件名为 `原文件名_disp_vel_subplots.png`。由于时间轴由 `fs` 重建，必须确认 `fs` 与真实采样率一致。

### 3.5 `generator.py`

`generator.py` 是 37 位六边形结构序列的核心生成器。

脚本根据用户指定的总点数生成由 `0` 和 `1` 组成的一行数据，并固定要求第 0 和第 36 个位置为 `1`。生成新序列时，它会比较已有序列的六种 60 度旋转结果，避免产生只是旋转角度不同、实际结构等价的重复数据。

主要命令行参数包括：

- 每行需要包含多少个 `1`；
- 一次追加多少行；
- 输入和输出 CSV；
- 是否允许第一次运行时缺少输入文件；
- 随机种子。

`--point-count` 表示一行中 `1` 的总数，合法范围是 2～37。首次生成且输入文件不存在时，需要增加 `--allow-missing-input`。例如生成一行包含 8 个 `1` 的结构：

```powershell
py -3.11 generator.py --point-count 8 --append-count 1 --allow-missing-input
```

当输入和输出都是默认的 `input.csv` 时，脚本在已有数据后追加；如果另外指定输出文件，该输出文件会被重新写入。通常不需要直接多次运行它，可以优先使用 `build_input_groups.py`。此外，`visualize_hex_lattice.py` 会导入这里定义的旋转函数。

### 3.6 `motion_profile.py`

`motion_profile.py` 用于生成“加速—匀速—减速”的梯形速度轨迹。

当前代码会依次生成 `0.1、0.2、0.3、0.4 m/s` 四档目标速度。内部运动计算使用米和米每秒，写入 CSV 前会转换成毫米和毫米每秒。

主要顶部参数包括：

- `T1`：加速和减速阶段的持续时间；
- `T`：一次完整运动的总时间；
- `VMIN`、`VMAX`、`VSTEP`：目标速度的起点、终点和步长；
- `DT`：相邻样本之间的时间间隔，单位为秒。

结果默认写入 `output/V_*.csv`。同名轨迹会被直接覆盖，不会额外询问；运行前应确认旧轨迹是否需要保留。这些文件可以继续交给 `adapter.py` 检查并重新编号。

### 3.7 `rotate_force.py`

`rotate_force.py` 用于把不同实验角度下采集的 `Fx/Fy` 旋转回统一的 0 度传感器坐标系。

坐标系是描述 X、Y、Z 方向的参考标准。如果不同角度的数据不先转换到相同坐标系，同一方向的力可能出现在不同列或带有不同正负号，无法直接比较。

脚本会从类似下面的文件名中读取角度：

```text
sensor_1_ang180.csv
```

旋转公式采用特定坐标约定：从俯视方向看，角度以顺时针为正，并假设 `Fy` 正方向朝西。如果实验设备采用不同的角度正方向或坐标轴方向，必须先修改公式或符号，否则结果方向会错误。

直接运行时，它会递归查找 `data` 及其所有子目录中的 sensor CSV，并保持相对于 `data` 的目录结构输出到 `data/datanew`。默认旋转倒数第 3 列和倒数第 2 列，也就是六列 sensor 数据中的 `FX` 和 `FY`。

该脚本目前没有命令行接口。可以修改 `batch_rotate_sensor_csvs_to_zero_frame()` 定义中的 `data_root` 和 `output_root` 默认值，也可以在其他 Python 代码中调用单文件函数：

```python
from rotate_force import rotate_force_csv_to_zero_frame

# delimiter 是分隔符；fx_col 和 fy_col 是从 0 开始的列位置，负数表示从末尾倒数。
# has_header=False 表示原始 CSV 没有表头。
rotate_force_csv_to_zero_frame(
    input_csv="data/model_1/sensor_1_ang60.csv",
    output_csv="data/datanew/model_1/sensor_1_ang60.csv",
    delimiter=",",
    fx_col=-3,
    fy_col=-2,
    has_header=False,
)
```

### 3.8 `visualize_hex_lattice.py`

`visualize_hex_lattice.py` 用于把 37 位结构序列画成一张六边形点阵大图，并同时为每组结构导出六种旋转图。

37 个点按照 `4-5-6-7-6-5-4` 的行数排列。脚本读取 CSV 中的数值，为不同数值设置颜色，并输出 SVG。它支持两种常见输入形式：一行 37 列，或者一列 37 行。

默认输入为 `input.csv`，大图默认输出为 `hex_lattice.svg`。旋转图按每组非零点数量排序，分别生成 `0°、60°、120°、180°、240°、300°` 六张 SVG，并保存在 `rotated_plots/group_XXX`。角度采用三位补零命名，例如 `rot_000.svg`、`rot_060.svg` 和 `rot_300.svg`。

常用命令行功能包括：

- 选择需要绘制的行；
- 显示 0～36 的点位编号；
- 调整多个样本的排列列数；
- 修改输入和输出文件。
- 通过 `--output-root` 修改旋转图输出根目录。

该脚本依赖 `generator.py` 中的六方向旋转函数。运行一次即可同时得到大图和所有旋转图。

## 4. 脚本之间的关系

可以把根目录脚本分成三条相对独立的流程。

### 4.1 六边形结构生成与可视化

```text
build_input_groups.py → generator.py → input.csv → visualize_hex_lattice.py
                                               ├→ 一张结构大图
                                               └→ 每组六张旋转图
```

- `generator.py` 负责生成单组或少量结构；
- `build_input_groups.py` 负责按项目配方批量调用生成器；
- `visualize_hex_lattice.py` 一次运行同时绘制结构大图和每组六种旋转结果。

### 4.2 运动轨迹生成与适配

```text
motion_profile.py → output/V_*.csv → adapter.py → output/renamed
```

- `motion_profile.py` 生成不同速度档位的运动轨迹；
- `adapter.py` 检查轨迹累计位移，并将文件重新编号。

### 4.3 实验原始数据处理

```text
sensor CSV → rotate_force.py → 统一坐标系数据
          └→ filter_sensor_data.py → 滤波数据

gather CSV → gather_data.py → 位移数据和曲线图
```

`rotate_force.py` 和 `filter_sensor_data.py` 当前没有互相调用。如果先统一坐标系再滤波，可以运行 `rotate_force.py` 生成 `data/datanew/...`，然后把对应的 `data/datanew/具体文件夹` 作为 `filter_sensor_data.py --input-path`。由于旋转是线性运算，理想情况下先旋转再线性滤波或先线性滤波再旋转应得到近似相同的结果；实际项目仍应固定一种顺序，避免文件来源和参数不一致。推荐先统一坐标系，再执行滤波和最终统计。

## 5. 运行前的通用注意事项

1. 推荐使用项目已安装依赖的 Python 3.11：

   ```powershell
   py -3.11 脚本名.py
   ```

2. CSV 文件名通常包含实验编号和角度。不要随意修改文件名，否则脚本可能无法识别。

3. 采样率 `fs` 必须与采集设备的真实设置一致。采样率错误会使时间轴和滤波截止频率的物理意义同时出错。

4. 原始 CSV 通常没有表头。不要手动添加列名，除非同时修改对应的读取逻辑。

5. 批量运行前建议先用一个文件验证参数、输出列数和单位，再处理完整数据集。

6. `rotated_plots`、滤波输出和绘图结果属于生成产物，通常不应重新加入 Git 追踪。
