# 维护者指南

本目录是一套面向人类维护者的项目说明。它回答“这个文件为什么存在、它表达什么物理量、什么时候应该运行哪个脚本、结果应该如何解释”，不解释函数内部的逐行实现。

## 推荐阅读顺序

1. [项目与物理背景](项目与物理背景.md)：先理解实验问题、坐标系、构型和科学边界。
2. [数据字典与文件物理意义](数据字典与文件物理意义.md)：确认每类文件的格式、单位、来源和权威性。
3. [脚本与端到端工作流](脚本与端到端工作流.md)：按任务查找脚本、命令、输入、输出和覆盖风险。
4. [训练产物与结果解释](训练产物与结果解释.md)：理解 checkpoint、预测表、指标和当前现有结果。
5. [维护规范与已知问题](维护规范与已知问题.md)：新增数据、修改实验、迁移机器或清理结果前阅读。

## 就近文档

- `Experiment/README.md`：实验目录内部导航。
- `model/README.md`：模型训练和评估的操作说明。
- `visualization/README.md`：可视化输入、输出及安全注意事项。
- `Experiment/实验方案与开发者快速上手.md`：更完整的实验参数说明。
- `model/模型文件夹脚本详细说明.md`：代码级实现参考。
- `model/plan.md`：模型设计阶段的长篇思路记录，不代表所有当前默认值。

## 文档口径优先级

当说明发生冲突时，按以下顺序判断：

1. 实际运行生成的 `resolved_config.json` 和数据文件内容；
2. 当前 `model/configs/*.yaml` 与脚本 `--help`；
3. 本维护者指南和各目录 README；
4. 设计记录、旧版脚本说明和历史示例。

其中“代码当前会做什么”和“团队希望什么文件成为正式版本”仍是两个问题。比如当前 `base.yaml` 确实读取根目录 249 条 `dataset.jsonl`，但正式汇总脚本的标准输出仍是 `Experiment/output/dataset.jsonl` 的 332 条完整基线。文档会同时陈述这两个事实，不擅自替项目负责人决定最终权威数据。

## 文档更新时间

本套维护者指南依据 2026-09-12 工作区内容编写。根目录数据与 `visualization/` 中部分文件存在未提交修改，因此数据条数和默认路径属于“当前工作区快照”；今后改变数据、配置或目录结构时，应同步更新文档。
