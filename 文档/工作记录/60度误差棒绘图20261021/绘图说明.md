## 输入与匹配

- 预测来自项目同级目录 `multiR_60deg_sample/cv_predictions.csv`，共 287 行，每个
  `sample_id` 只有一条测试集预测。五折分别为 58、58、57、57、57 个测试样本。
- 实验来自 `datasets/multi_stiffness/repeatability.csv`，共 1224 个工况；按

- 覆盖全部合格的 60° 整数倍样本，即 0°、60°、120°、180°、240°、300°。
  四个短记录的 10000% 标记没有参与绘图或 SD 计算。

## 统计定义

每个工况两轮 FX_0 分别为 F1 和 F2，单位 N。先计算双轮均值，再计算样本标准差：

```text
mean = (F1 + F2) / 2
SD = sqrt(((F1-mean)^2 + (F2-mean)^2) / (2-1))
   = abs(F1-F2) / sqrt(2)
误差棒下界 = mean - SD
误差棒上界 = mean + SD
```

这里 F1/F2 是先前完成时间截取、低通、截尾平均和力旋转后的逐轮汇总值，
SD 描述两次实验之间的离散程度。没有把一轮内的 1990 个时间采样点当作独立
重复实验。图中误差棒为 n=2 的 ±1 个样本 SD，不标为 95% 置信区间。

绘图中心使用重复性 CSV 的完整精度均值；预测 CSV 的目标值经过 float32
转换，二者最大偏差为 2.3566652e-7 N，处于该转换的精度范围内。所有 287 个
样本的目标值都与相应双轮均值通过核对。样本 SD 范围为
0.000386985367～0.341660985641 N。

模型预测使用现成的各折测试集结果；每个样本只有一个测试预测值，没有据此
估算模型预测分布。绿色曲线沿用原图中的 `isolated_drag` 单株阻力叠加基线。

```powershell

```

默认拒绝覆盖已有结果。如需重画，可追加 `--overwrite`；或用 `--output-stem`
和 `--audit-dir` 分别指定新的图片路径前缀和工作记录目录。所有默认参数集中在
脚本开头；也支持 `--dpi`、`--marker-size`、`--line-width` 等 CLI 参数。

标签的一致性。输出图的 287 条误差棒数量已核对，并验证 PNG 可以完整读取、
像素尺寸为 10800×3600。已目视检查预览：标签未截断、中文无缺字、图例和
误差棒显示正常。输入文件的 SHA-256 校验值在绘图前后保持一致。

`绘图摘要.json` 保存参数、各折/角度计数、输入与输出的 SHA-256 校验值，
`绘图预览.png` 和 `误差棒细节预览.png` 用于本次视觉检查。重算 SD 可直接读取外部输出的数据 CSV。
