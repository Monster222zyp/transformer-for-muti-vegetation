## 全量校验结论

迁移前先核对递归文件清单与上述十份 datasets 路径完全一致，确认根目录 `dataset_initial.jsonl` 不存在且不创建。所有目标原本没有 stiffness 字段，原 schema 均为 1 或 2。

ZIP 备份完成后，重新读取每个 ZIP 成员，逐字节核对其内容等于迁移前文件。新内容先写到每份数据所在目录的临时文件，再用 `os.replace` 原子替换该文件；这里的原子性是针对单个文件，11 份文件并非一个文件系统事务。迁移发生异常时可从已核实的备份恢复。

迁移后重新读取所有正式文件，逐行验证 schema=3、每株 EI 为正有限数 1.0。移除新增 stiffness 并还原该记录原 schema 后，与迁移前 JSON 对象进行深比较，4,606 条全部一致。这确认测量值、角度、坐标、sample_id、model_id、排布、其他字段、样本与植株顺序均未变化。JSONL 的空白和排版可能因统一序列化变化，迁移前的原始字节保存在 ZIP。

每份文件的迁移前后 SHA-256（内容摘要）、数量、原 schema、验证结论及完整备份路径保存于 [migration_manifest.json](migration_manifest.json)。

## 备份与恢复

可恢复备份为 [dataset_before_ei_v3_20261006.zip](dataset_before_ei_v3_20261006.zip)。ZIP 内仅包含上表的 11 个原始文件，成员路径以项目根为起点，并保留中文文件名和迁移前完整字节。

ZIP 的 SHA-256 为 `50223dbdfc992340f886c9979ebc10ea4a7278b25853cbd4e38ca72deef777ae`。需要恢复时，先备份迁移后的当前数据，再在项目根目录执行以下命令，仅解压到独立恢复目录进行检查：

```powershell
# 所有运行路径集中在开头；必须从本项目根目录执行。
$projectRoot = (Get-Location).Path
$auditDirectory = Join-Path $projectRoot '文档\工作记录\角度刚度编码器'
$backupPath = Join-Path $auditDirectory 'dataset_before_ei_v3_20261006.zip'
$restoreDirectory = Join-Path $auditDirectory 'restore_before_ei_v3'

# Get-FileHash 计算 ZIP 摘要，先与本清单中的 SHA-256 核对。
Get-FileHash -LiteralPath $backupPath -Algorithm SHA256

# Expand-Archive 只恢复到独立目录；没有 -Force，已有恢复目录冲突时不会主动覆盖。
Expand-Archive -LiteralPath $backupPath -DestinationPath $restoreDirectory
```

确认恢复目录内容后，需要把这 11 份文件恢复到项目时，再执行下面的定向复制。此步会用迁移前数据覆盖目标文件，仅在确实需要撤回此次字段迁移时使用：

```powershell
# 从同一独立工作目录加载精确目标清单，避免递归复制无关内容。
$manifestPath = Join-Path $auditDirectory 'migration_manifest.json'
$manifest = Get-Content -LiteralPath $manifestPath -Raw -Encoding UTF8 | ConvertFrom-Json

# 每次仅复制清单中的一份原始数据，恢复旧 schema，并删除此次新增的 stiffness。
foreach ($target in $manifest.targets) {
    $sourcePath = Join-Path $restoreDirectory $target.path
    $destinationPath = Join-Path $projectRoot $target.path
    Copy-Item -LiteralPath $sourcePath -Destination $destinationPath -Force
    # 恢复后的摘要应与该目标的 before_sha256 完全相等。
    Get-FileHash -LiteralPath $destinationPath -Algorithm SHA256
}
```

恢复不会改动两个排除副本。备份、manifest 和本清单应一同保留，不应因开始新训练而清理。
