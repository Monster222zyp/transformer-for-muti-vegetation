# 预测—实测散点图坐标范围调整

日期：2026-10-21。

## 原因与改动

原绘图函数将原始实测值、模型预测和 baseline（逐株孤立阻力相加的对照预测）合并后确定两图共用范围。现有 287 条记录中，baseline 最大约 32.75 N，模型预测最大约 7.53 N，因此模型散点被压缩在左下角。

现在默认每张图只用本图实测与预测确定范围，仍包含零点、两端各留 5%，图内 x、y 保持同范围、等比例，并保留 `y=x` 参考线。全部原始记录、负实测值处理和误差计算口径均保留。图下注明当前范围模式。baseline 的统计框移动到右上方，避开左上方的高估样本。

配置位于 `model/configs/base.yaml`：

```yaml
output:
  drag_parity_axis_mode: independent
```

`independent` 表示两图独立取范围，`shared` 表示两图共用范围。训练命令行 `--drag-parity-axis-mode shared` 可覆盖 YAML，最终模式写入配置快照。独立范围下，跨图比较绝对误差需读刻度及 MAE（平均绝对误差）、RMSE（均方根误差），不能只看点到参考线的像素距离。
