# 逐株系数绘图脚本修复

日期：2026-10-22。

## 问题原因

`visualization/plot_plant_coefficients.py` 的 `predict_all_samples` 已通过 `HydroDataset` 和 `collate_hydro_samples` 取得逐株角度及弯曲刚度，但调用模型时仅传递位置、单株阻力、全局特征和有效株掩码。

当前 `HydroTransformer` 必须同时接收 `plant_angles` 和 `plant_stiffness`，因此旧调用触发“新模型需要 plant_angles 和 plant_stiffness，不能使用旧共享 Token 输入”。这是绘图脚本的调用遗漏，现有 checkpoint 无需重新训练。

## 修复内容

- 从整理后的输入读取 `plant_angles`、`plant_stiffness`，迁移到模型所在设备，并明确传入模型。
- 两项输入形状均为 `[B,N]`：B 为样本数，N 为逐株位置数量；与位置及有效株掩码对齐。角度保留 degree，EI 保留 N·m²。
- 修正帮助文字中遗留的 `interpretability/` 路径以及把 JSONL 误称为 CSV 的注释。
- 更新目录 README，说明当前输入以及低 EI 告警与接口异常的区别。

## 验证结果

1. 新增 `model/tests/test_plot_plant_coefficients.py`。CPU、CUDA 各一项，共两项通过。测试使用真实小模型及不同株数、不同角度和 EI 的输入，核对脚本结果与模型直接调用结果，以及逐株系数与总阻力的关系。
2. 使用用户现有 `model/artifacts/final_model.pt` 和默认 JSONL，在 CUDA 上完成全部 287 个样本、2755 株水草的推理；所有总阻力和逐株系数均为有限值，坐标与系数数量一致。
3. 复制真实首行记录到本目录的 `单样本验证.jsonl`，保留原绘图参数，通过真实命令行生成点图与 Gaussian 影响图。命令从 `visualization` 目录执行，退出码为 0，两张图均已目视检查。
4. 验证输出独立保存在本目录的 `真实样本预览/`；未执行默认输出目录的清理与全量绘图。

全量推理仍记录到低 EI 的 `NumericalStabilityWarning`：EI 为 `8e-7` 或约 `5.907e-6 N·m²` 时会触发提示。本次告警未阻止求解；输出有限仅证明本次推理完成，不能单凭这一点证明所有物理求解均稳定。修复没有改大实测 EI 或屏蔽告警。

详细摘要见 `验证结果.json`，单样本命令行输出见 `实际运行日志.txt`。
