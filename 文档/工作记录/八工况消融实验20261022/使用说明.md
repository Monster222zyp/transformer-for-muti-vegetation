# RoPE 与 relative value 八工况批量消融

脚本为 `model/run_ablation.py`。消融实验是有控制地关闭模型机制、保持其他条件
一致，从而比较这些机制对预测表现的影响。RoPE 是旋转位置编码，用于把位置
关系加入注意力计算；relative value 是向注意力输出加入相对几何信息的分支。


该目录已通过 `--dry-run` 生成八份配置、批次清单，以及八行待运行比较表。
**尚未启动正式模型训练，当前指标为空。** 配置使用 `model/configs/base.yaml`
及训练模块现有默认值补全规则，不修改基准 YAML 或模型实现。

| split_mode | use_rope | use_relative_value |
|---|---|---|
| sample | true | true |

| sample | false | true |
| sample | false | false |

| plant_count | false | true |

`sample` 按单条样本随机划分；`plant_count` 将植株根数相同的全部样本视为一组，
同组不跨训练、验证、测试集合。后者用于检验模型对未参与训练的根数的泛化表现，
不是按根数做分层随机抽样。两种划分的任务不同，脚本仅在同种划分内部标注最优值。

当前基准数据为仓库根 `dataset.jsonl`，共 **1197 条全角度记录**，根数为
4、5、6、8、10、12、18、20、22。当前默认 seed=20260816、5 折、验证比例 0.2、
batch size=32、最多 500 epoch、early stopping patience=100、device=auto。
epoch 是遍历训练数据一次；early stopping 是验证表现持续不改善时提前停止。
同种划分的四个工况共用数据、种子和其他参数，方向注意力和其他条件化开关保持不变。

## 比较表与指标含义

`comparison.csv` 使用带 BOM 的 UTF-8，方便 Excel 打开中文。`comparison.md`
提供可读表格；开始和结束每个工况时均会自动刷新。状态包括 `prepared`、
`running`、`completed`、`failed`、`interrupted` 和产物不完整时的 `incomplete`。

主要指标直接取 `artifacts/cv_metrics.json`：

- `aggregate.MAPE_D`：平均绝对百分比误差，已经是百分数，**越小越好**。
  仅实验目标值大于 1e-6 N 的样本参与；`MAPE_coverage` 保存参与比例。
- `aggregate.R2`：决定系数 R²，**越大越好**；合法负数会保留，目标全常数时无定义。

这里的 aggregate 是将所有折未参与训练和 early stopping 的测试预测合并后，
重新计算得到的整体指标。没有简单平均各折 R² 或 MAPE，也不拿全量重训模型
对训练数据的拟合分数作为这张表的比较结果。附带列还包括 RMSE_D、折数、耗时、
退出码、产物与日志路径、失败原因，并标记同种划分内的最低 MAPE_D 和最高 R²。

尚未完整完成或无数学定义的指标留空，不以 0 替代。即使 `cv_metrics.json`
已存在，也必须进程成功、全部折完成、`final_retraining_performed=true`、
`final_model.pt` 非空且配置快照匹配，才标为 `completed`。

## 续跑、失败与修改参数

再次运行同一命令会跳过完整成功的工况，失败或中断的工况重新完整训练。
当前项目的 CV 流程不支持从某一折 checkpoint 续训，因此这里的续跑是批次层面
跳过已经完成的工况。Ctrl+C 会停止当前子进程并保存状态；默认一个工况失败后
仍继续其他工况，最后以非零返回码表示批次有失败。

```powershell
# 只更新已有批次的比较表，不训练。
& 'C:\Users\Mayn\miniconda3\envs\Transformer\python.exe' -m model.run_ablation --summarize-only

# 失败后立即停止，而不是继续其余工况。
& 'C:\Users\Mayn\miniconda3\envs\Transformer\python.exe' -m model.run_ablation --fail-fast

# 只回显工况进度；各 epoch 的完整日志仍保存在 training.log。
& 'C:\Users\Mayn\miniconda3\envs\Transformer\python.exe' -m model.run_ablation --quiet
```

`--config`、`--data`、`--device`、`--max-epochs`、`--batch-size`、`--seed` 和
`--n-splits` 都对八个工况统一应用。比如，若要改用此前提取的 287 条六角数据，
应选择新的批次目录，避免与已准备的 1197 条实验混用：

```powershell
& 'C:\Users\Mayn\miniconda3\envs\Transformer\python.exe' -m model.run_ablation `
  --data 'datasets/multi_stiffness/dataset_60deg.jsonl' `
  --output-dir '..\ablation_rope_relative_value_60deg_20261022'
```

脚本记录数据、物理配置、基准 YAML 及训练代码的 SHA-256 校验值；它们发生
变化时，拒绝复用同一批次目录。SHA-256 是文件内容的校验值，用于确认是否为
相同输入。`--summarize-only` 仍可读取已有历史结果。显式使用
`--rerun-completed` 会完整重训成功工况，并由训练入口清理对应的旧 artifacts。
默认不执行该操作。批次文件锁防止两个运行器同时操作同一目录。

## 验证范围

新增 `model/tests/test_ablation_runner.py`，只使用临时文件和模拟训练产物：

1. 八组合完整，除指定开关、划分及输出路径外，配置逐项相同。
2. 比较表提取 aggregate，而不是取第一折或平均折指标；保留负 R²、将 NaN 留空。
3. 已完成工况不重跑；失败继续，续跑只重试失败工况。
4. 部分 CV 结果或全量重训标记为 false，不能冒充完整成功。
5. 数据改变时拒绝混入旧批次，已有历史结果仍可单独汇总。
6. 子进程参数以列表传递，路径含空格可用，中文日志使用 UTF-8。
7. 中断状态落盘，且不启动后续工况；不接管含有其他文件的输出目录。
