# 二、立项依据

## （一）项目的意义

水生植被是河流、河口与近岸生态系统的重要组成部分，其作用不仅体现在生境维持，也体现在对水流和泥沙输运的调节。植被通过承受水动力载荷与水流交换动量，改变局部流速、尾流及湍流结构，进而影响周围区域的沉降与输运条件。已有植被斑块实验表明，植被产生的尾流结构与泥沙沉降分布密切相关，但不同位置的作用并不相同。因此，准确描述水草的水动力响应，是评价植被水流调控作用、开展生态修复与人工植被工程设计的重要基础。[Chen 等，2012](https://doi.org/10.1029/2012WR012224)

实际水草及其仿生结构通常具有不均匀的刚度分布：茎秆承担支撑作用，叶片则更容易在水流作用下弯曲。叶片随水流调整形态的过程称为“流致重构”，它会改变有效迎流面积和受力方向，使阻力响应不同于形状固定的刚性障碍物。对于刚性茎秆与柔性叶片组成的复合结构，单一刚性圆柱或均质柔性梁的简化未必能够同时表达各部件的响应，需要结合具体形态和来流条件评价其适用性。[Luhar 和 Nepf，2011](https://doi.org/10.4319/lo.2011.56.6.2003) 本项目拟研究刚柔复合单株的受力分配与流致重构机制，进一步阐明群体排列对株间干扰的影响，并建立连接二者的分层预测方法。

从单株推广到群体后，水草之间的水动力干扰进一步增加了问题复杂性。上游植株的尾流可能减弱下游植株的受流作用，而横向间隙的收缩又可能提高局部流速，分别形成遮蔽与阻塞效应。二者受空间排列共同控制，不能仅凭株数或平均密度推断群体阻力。[Liu 和 Wang，2024](https://doi.org/10.1029/2023WR036521) 当平面坐标、逐株刚度、整体朝向和流速共同变化时，候选工况迅速增加，对所有组合进行实验或精细数值计算将面临较高成本。为此，有必要建立单株物理模型与深度学习协同的快速预测方法，并以自动化实验和主动学习提高数据获取效率。

本项目拟以稳态来流中完全淹没的仿生水草为研究对象，保持同一构型内所有植株同向，研究整体朝向变化、逐株不同刚度及连续平面布局下的水动力响应。预期成果将为水草阻力评估、人工植被布置及材料选择提供依据，并为后续较大尺度的植被水动力模型提供经过验证的阻力描述；对波浪、野外复杂环境等条件的应用则需要进一步独立评价。

## （二）国内外发展现状分析

### 1. 单株受力与柔性重构研究

国际上，植被受力研究已从刚性障碍物的阻力描述，发展到考虑流体作用与结构变形相互影响的流固耦合建模。Luhar 和 Nepf 建立了柔性水生植被的重构模型，分析水动力、弹性和浮力共同作用下的形态变化，说明柔性变形能够改变阻力随流速增长的规律。[Luhar 和 Nepf，2011](https://doi.org/10.4319/lo.2011.56.6.2003) 对更复杂的植株结构，Zhang 和 Nepf 在波浪条件下分别描述叶片与中央茎的重构，并结合活体及仿生植株评价整株受力，为部件化建模提供了研究基础；其波浪载荷条件与本项目的稳态来流条件需要明确区分。[Zhang 和 Nepf，2021](https://doi.org/10.1016/j.jfluidstructs.2020.103192)

国内研究也在持续深化柔性植被的阻力与重构机制。武汉大学与南京水利科学研究院合作开展的淹没柔性单株实验，分析了流速、植株尺寸和弯曲姿态对受力的影响，并结合 Reynolds number、Cauchy number 和弯曲角建立阻力系数经验关系。其中，Reynolds number 表征惯性与黏性作用的相对大小，Cauchy number 表征流体载荷与弹性抵抗的相对大小。该研究进一步说明，柔性植被阻力需要考虑形态变化及不同受力组成，但其对象为柔性圆柱，并非刚茎—柔叶复合植株。[Liu 等，2026](https://doi.org/10.1029/2025WR043108)

总体而言，单株研究已经形成重要的力学与实验基础。对于具有多叶片和刚柔差异的植株，仍需结合具体结构研究茎叶受力分配、叶片重构及单株内部遮蔽，避免以一种简化形态替代全部结构响应。

### 2. 群体空间排列与植株间相互作用研究

植被群体阻力研究已覆盖规则和随机排列，并非仅限于固定格点。Tanino 和 Nepf 对随机刚性挺水圆柱阵列开展实验，研究阵列密度和 Reynolds number 对平均阻力系数的影响，说明群体受力具有不同于孤立单体的特征。[Tanino 和 Nepf，2008](https://doi.org/10.1061/(ASCE)0733-9429(2008)134:1(34))

国内北京林业大学团队进一步区分了纵向遮蔽与横向阻塞的作用，研究纵横间距对局部受流条件和阻力的影响，并提出同时考虑两类效应的参考流速表达。这为分析相同密度下不同排列产生的受力差异提供了依据。不过，该模型针对刚性挺水圆柱及顺列布局，其结论向完全淹没的刚柔复合水草推广时，仍需考虑叶片变形与结构差异。[Liu 和 Wang，2024](https://doi.org/10.1029/2023WR036521)

在高精度数值模拟方面，Löhrer 和 Fröhlich 对由大量柔性叶片构成的淹没冠层进行了流固耦合大涡模拟，解析了冠层变形、集体运动与流场之间的联系。这说明复杂柔性群体的相互作用已有精细研究基础，但逐个解析结构变形与流场的计算方式，不宜直接替代大规模候选构型筛选所需的快速预测工具。[Löhrer 和 Fröhlich，2025](https://doi.org/10.1017/jfm.2025.407)

因此，本项目关注的不是首次研究排列效应，而是将刚柔复合单株的响应与株间干扰衔接起来，在明确研究范围内建立适用于多种布局和物理条件的快速预测方法。

### 3. 深度学习中的空间关系表征与物理信息融合

植被群体的水动力响应不仅取决于各株自身的形态和材料属性，也受到相对位置及上下游关系的影响。因此，面向植被群体的深度学习建模需要表达植株之间的空间联系，而不能仅依赖株数、平均密度等整体指标。如何将空间关系纳入非线性交互的描述，是连接几何构型与群体受力的重要问题。

近年来，Transformer 中的位置编码研究为元素间关系的表达提供了新的方法。Su 等提出的 RoPE（Rotary Position Embedding，旋转位置编码）通过旋转变换将位置信息引入自注意力计算，使相对位置参与元素间关联的表达。[Su 等，2024](https://doi.org/10.1016/j.neucom.2023.127063) Shaw 等提出的相对位置表示进一步将元素间关系纳入注意力计算和 Value（参与加权聚合的信息向量）的聚合过程，使位置关系不仅影响交互权重，也参与传递信息的构成。[Shaw 等，2018](https://aclanthology.org/N18-2074/) 这些研究为空间位置与交互关系的联合表征提供了方法依据，但其原始验证对象为语言序列，对植被水动力问题的适用性仍需结合具体物理过程评价。

与此同时，物理知识与深度学习的融合已在环境过程预测中得到探索。Read 等在湖泊水温研究中结合过程模型、观测数据和能量守恒约束，建立过程引导的深度学习方法，表明物理知识能够通过模拟数据与物理约束参与模型学习。[Read 等，2019](https://doi.org/10.1029/2019WR024922) 这类研究为兼顾物理意义与复杂关系表达的建模提供了基础。

对于柔性植被群体，空间交互还伴随着叶片重构、材料刚度和来流条件的共同变化。如何在保留单株力学响应的基础上，描述连续布局下的株间干扰及其随物理条件的变化，是建立快速、可靠群体阻力预测方法需要进一步研究的问题。空间关系表征与单株物理机理之间的衔接，因而具有明确的研究必要性。

### 4. 自动化实验与主动学习研究

单株及群体水动力研究通常需要改变材料、几何或工况并测量受力。对于连续布局、多刚度和多朝向的联合条件空间，数据需求不能仅依靠增加固定间隔的实验点来满足。本项目拟通过自动旋转和同步受力采集，复用同一水草构型获取多个整体朝向的实测数据，降低重复搭建与人工操作成本。

主动学习（Active Learning）通过模型预测及其不确定性选择后续测量工况。Kusne 等在材料研究中建立了主动学习实验闭环，根据预测及其不确定性选择后续测量，并将新数据反馈到模型。[Kusne 等，2020](https://doi.org/10.1038/s41467-020-19597-w) 这一思路为本项目提供了可借鉴的实验设计方法：自动化设施提高单次采集效率，主动学习提高实验选择和样本利用效率。两者结合，有望在给定实验预算下更有效地完善模型，但其收益需要通过本项目实验评价，不能直接移用其他领域的提升倍数。
